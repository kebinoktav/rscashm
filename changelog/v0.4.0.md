# RSCashM 0.4.0

This release adds password-based encryption for ledger files.

## Added
- Added password-based encryption for ledger files, with actions to check encryption status, unlock files, and re-encrypt them.
- Encrypted ledger files must be unlocked with the correct password before they can be edited.

## Installation Paths

Default installation paths when using the default prefix (`~/.local`):

- **Launcher:** `~/.local/bin/rscashm`
- **Application binary:** `~/.local/lib/rscashm/rscashm`
- **Desktop entry:** `~/.local/share/applications/rscashm.desktop`
- **Application icon:** `~/.local/share/pixmaps/rscashm.png`
