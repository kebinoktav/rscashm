# RSCashM 0.3.0

This release introduces a new Iced-based graphical interface, expanded appearance customization, currency support, and improved ledger-file management.

## Added
- Added support for multiple currencies.
- Added a Settings menu with options to customize the application theme, background color, text color, and wallpaper.
- Added support for selecting and managing multiple ledger files.
- Added an installation script and desktop entry for launching RSCashM from the desktop application menu.

## Changed
- Replaced the egui-based interface with Iced and reworked the application interface and internal logic.
- Empty ledger files now open with a zero balance and no transaction history.
- The installer now uses `~/.local` as the default installation prefix and supports custom prefixes through the `PREFIX` variable.
- The desktop entry now references the launcher and icon paths corresponding to the selected installation prefix.
- User data is stored separately in `${XDG_DATA_HOME:-~/.local/share}/rscashm/`.

## Fixed
- Fixed an issue where selecting a different ledger file did not update the displayed file or the active file path.

## Configuration and Data
- Application settings are now stored in `config.json` within the user's RSCashM data directory.
- If `config.json` is missing or contains invalid data, the application falls back to the legacy `cfg.txt`, `theme.txt`, and `appearance.json` configuration files.
- Ledger transactions continue to be stored separately in binary `.bin` files.

## Installation Paths

Default installation paths when using the default prefix (`~/.local`):

- **Launcher:** `~/.local/bin/rscashm`
- **Application binary:** `~/.local/lib/rscashm/rscashm`
- **Desktop entry:** `~/.local/share/applications/rscashm.desktop`
- **Application icon:** `~/.local/share/pixmaps/rscashm.png`
